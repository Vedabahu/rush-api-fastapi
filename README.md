# Rush API - Club event 2025

This repo contains the code for the Maze for the even **Rush API** by the **club Techniosys**.

## Usage

- Download the tool called [uv](https://docs.astral.sh/uv/getting-started/installation/)
- Clone the repo: `git clone https://github.com/Vedabahu/rush-api-fastapi.git`
- Change directory: `cd rush-api-fastapi`
- Start the fast-api server: `uv run fastapi main.py`

## Some notes on contribution

- Create a fork and make your changes there are create a [pull request](https://docs.github.com/en/pull-requests).
- Always create a [pull request](https://docs.github.com/en/pull-requests) for any changes.
- Point the PR to the `dev` branch and not the main branch.
